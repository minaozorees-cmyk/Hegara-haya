# 💰 صندوق الخدمة

تطبيق ويب عربي (RTL) لإدارة صندوق الخدمة: العمليات المالية، الحسابات، المناسبات والتعهدات، التقارير، والتصدير إلى Excel/PDF.

## المزايا
- يعمل بالكامل بدون إنترنت وبدون مكتبات خارجية (ملف HTML واحد).
- قفل بنمط الرسم (Pattern).
- تخزين محلي على الجهاز (IndexedDB مع بديل localStorage).
- نسخ احتياطي واستعادة بصيغة JSON.
- قابل للتثبيت كتطبيق (PWA) على الهاتف.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع كل الملفات.
2. من **Settings ← Pages**: اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقائق يظهر الرابط: `https://USERNAME.github.io/REPO/`

## التثبيت على الهاتف
افتح الرابط في Chrome ثم القائمة ← **إضافة إلى الشاشة الرئيسية**.

## ملاحظة
البيانات محفوظة في متصفح كل جهاز ولا تُرفع لأي خادم. خذ نسخة احتياطية (تصدير JSON) بشكل دوري.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.json` | إعدادات التثبيت (PWA) |
| `sw.js` | العمل بدون إنترنت |
| `icon.svg` | الأيقونة |
| `.nojekyll` | تعطيل معالجة Jekyll |
